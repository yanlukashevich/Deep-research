# Примеры отчётов

Реальные прогоны агента, сохранённые как есть — ничего не редактировалось вручную. Каждый отчёт
воспроизводится командой из колонки «как повторить» (ответы могут отличаться: веб меняется).

Формат один и тот же: `report.md` для чтения, `report.json` — то же самое машинно-читаемо
(предложения, их оценки, цитаты, статистика прогона). Для одного примера приложен ещё и `trace.jsonl` —
полный журнал шагов агента.

Отдельно:

- [04-isp-ran-ivannikov-v3.trace.jsonl](04-isp-ran-ivannikov-v3.trace.jsonl) — 42 события того же прогона:
  план, каждый поиск, каждая прочитанная страница, извлечённые факты с цитатами, проверка цитат,
  вердикт критика, финальный текст. Именно этот поток событий веб-интерфейс показывает вживую.

## Как повторить

```
python -m taro "Who won the 2026 FIFA World Cup and what was the score in the final?" --mode v3
python -m taro "Who won the 2026 FIFA World Cup and what was the score in the final?" --mode v1
python -m taro "Какой клуб выиграл Кубок Гагарина в 2026 году и кого он обыграл в финале?" --mode v3
python -m taro "Сколько лет прошло между основанием ИСП РАН и смертью его основателя Виктора Иванникова?" --mode v3
python -m taro "How many moons does Mercury have, and what are their names?" --mode v3
```

Результат каждого прогона кладётся в `runs/<дата-время>-<режим>/`.

## На что смотреть в отчёте

- **Цвет у каждого предложения.** 🟢 ≥ 0.75 · 🟡 ≥ 0.5 · 🔴 ниже. Оценка считается из того, **сколько
  разных сайтов** процитировано и какого они качества, а не из того, насколько уверенно звучит текст.
- **Цитаты под каждым источником** — это ровно те строки, которые проверены точным поиском по тексту
  страницы. Любую из них можно открыть по ссылке и найти на странице.
- **«What we couldn't find»** — подвопросы, на которые фактов не нашлось. Агенту разрешено этого не
  скрывать, и это снижает итоговую уверенность.
- **Источники с пометкой `_(read, but the answer does not cite it)_`** — страницы, которые дали
  проверенный факт, но писатель им не воспользовался. Они остаются в списке, чтобы нумерация не ехала.
